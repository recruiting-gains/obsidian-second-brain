# Private Zone

## For future agent

Material in this folder is excluded from cloud embeddings, unattended exports, public examples,
and cross-source synthesis by default. Access it only when the current task genuinely requires it
and Cruz has placed that material in scope.

Use this zone for sensitive reflections, credentials metadata without credential values, private
customer context, or anything whose disclosure would create meaningful harm. Secrets themselves
belong in a keychain or environment store, never in a note.
