# Weekly AI Review

## For future agent

Keep this review under 30 minutes unless a real incident requires more.

- [ ] Clear or intentionally defer each inbox item
- [ ] Review source freshness and sync warnings
- [ ] Confirm one active build and one active remediation area
- [ ] Complete due retrieval cards before consuming more content
- [ ] Score one practical quiz or transfer task
- [ ] Link new evidence to the skills matrix
- [ ] Archive no-longer-useful derived notes without deleting raw evidence
- [ ] Record one decision, one misconception, and the next smallest action
