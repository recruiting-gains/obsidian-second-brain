# Record the Neural Glass Demo

This is a 30-45 second, privacy-safe walkthrough. Use only the sanitized demo note and system map.
Do not improvise with the global graph, source folders, raw records, local paths, or private notes.

## Before recording

- Open [[80 Dashboards/Neural Glass Demo|Neural Glass Demo]] and close every other tab.
- Collapse the file explorer or keep only `80 Dashboards` expanded.
- Confirm the demo warning says `SANITIZED DEMO` and `NO PRIVATE CONTENT`.
- Keep Obsidian Sync and Publish disabled.
- Disable notifications and hide unrelated desktop windows.
- Use a 9:16 crop centered on the note; verify text remains readable before recording.
