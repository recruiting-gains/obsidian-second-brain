# Evidence of Mastery

## For future agent

Evidence is an immutable or versioned pointer to something Cruz actually did: commit, test report,
demo, design defense, eval result, interview synthesis, incident response, user outcome, or handoff.
Certificates and completion time may provide context but never establish mastery alone.

Every evidence note records competency id, artifact, prompt or task, rubric, score, reviewer, observed
mistakes, next review, and sources. Use `schemas/learning-evidence.schema.json` when exporting evidence
as JSON.
