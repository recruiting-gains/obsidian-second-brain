# Weekly Quiz Bank

## For future agent

Generate each quiz from current misconceptions and the active build. Keep answers and scoring rubric
hidden until Cruz commits an answer. Every fourth week, replace the quiz with a blind integration gate
and a five-minute oral defense.

## Weekly shape

- Five short closed-book recall prompts
- Two transfer scenarios in unfamiliar contexts
- One debugging or design task
- One "explain this trade-off to a customer" prompt

## Starter prompts

1. Why can a retry create duplicates even when the first request returned an error?
2. Distinguish source time, observation time, and processing time with one example.
3. What evidence proves a raw archive is immutable in practice, not only by policy?
4. Why is a system prompt not an authorization boundary?
5. When should a retrieval system abstain?
6. Design a stable identity for a source that has no external id and changes formatting.
7. A generated note contains a corrected user paragraph. How should the next sync behave?
8. Diagnose whether a wrong answer came from retrieval, reasoning, or stale source data.
9. Explain to a customer why "ingest everything" creates risk and often reduces usefulness.
