# FDE Baseline Assessment

## For future agent

Administer practical tasks without step-by-step hints. Preserve the prompt, artifact, output, rubric,
mistakes, and a short oral explanation. Use the result to skip mastered material.

## Tasks

1. Repair and test a small Python ingestion script containing one correctness bug and one unsafe write.
2. Add one endpoint to a tiny web service and write its contract test.
3. Query, deduplicate, and reconcile a deliberately messy dataset.
4. Containerize and run the service from a clean checkout.
5. Draw and defend the architecture, including failure and privacy boundaries.
6. Conduct a 15-minute mock discovery conversation and turn it into measurable success criteria and a
   smallest useful pilot.

## Rubric per competency

- `0`: cannot yet explain or perform it.
- `1`: completes only by following an example.
- `2`: completes with targeted hints.
- `3`: completes, tests, and explains independently.
- `4`: operates under failure, teaches the approach, and makes sound trade-offs.
